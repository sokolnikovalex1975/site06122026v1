# Тестовая главная по результатам аудита

Предпросмотр: https://sokolnikovalex1975.github.io/site06122026v1/preview-audit/

Это отдельный каталог для анализа владельцем. Корневая главная, остальные страницы и рабочий Timeweb не изменяются.

## Изменения

- Лицензия и юрлицо на первом экране, отдельный блок исполнителя.
- Состав абонентской платы и дополнительных работ раньше по странице.
- Нет выдуманной цены «от»: индивидуальный расчёт до утверждения прайса.
- Типовые задачи раскрываются по желанию, без выдачи за реальные кейсы.
- Отчёт с пометкой об условных данных.
- Отдельное неотмеченное согласие и постоянные подписи полей.
- Исправление узкого hero, более компактные мессенджеры на телефоне.
- Кнопка «Показать изменения» включает пояснения; по умолчанию чистый макет.

## Безопасный режим

- `noindex, nofollow, noarchive`.
- Форма проверяется только в браузере. POST/fetch/send.php отсутствуют, ничего не сохраняется.
- Без JS поля disabled; передача данных в URL невозможна.
- Метрика, UIS и Radist не запускаются в предпросмотре.
- Производственные ID, настройки подмены, цель `audit` и Radist остаются в неизменённом `../server/counters.html`.
- Самостоятельно переносить тестовый обработчик на Timeweb нельзя.

Ориентир SHA-256 файла production-интеграций до изменений:
`3c4a1e15f773b49bbde7e69f5f8168aaa1c51f22a1d3dc338798e53be47fb652`.

Для production отдельно требуются утверждение тарифа и текста согласия, серверная проверка согласия, запись редакции документа, реальная тестовая заявка и проверка почты/CRM/целей/подмены номера. Тестовая страница не является production-релизом.

Ресурсы и происхождение перечислены в `assets/asset-manifest.md`.
