# Страница «Дезинфекция для организаций»

Адрес: `/dezinfektsiya/`. Первый пункт меню «Услуги» (шапка, мобильное меню, подвал) на всех страницах сайта.

Зонтичная страница: классическая дезинфекция (обеззараживание от бактерий, вирусов, грибов и спор) и все услуги компании,
которые по п. 79–80 СанПиН 3.3686-21 входят в дезинфекционную деятельность, — профилактическая дезинфекция (плановая
и внеплановая), смывы и лабораторный контроль, очистка и дезинфекция вентиляции, дезинсекция, дератизация, санитарный аудит
(СЭС-аудит), пест-контроль по IPM и договор.

**Заключительную (очаговую) дезинфекцию компания не проводит** — на странице её нет ни в услугах, ни в видах, ни в вопросах,
ни в форме заявки (решение пользователя 06.11.2026). Не возвращать при правках.
Подробные разделы о вентиляции и аудите не повторяют отдельные страницы — короткий блок и ссылка.

## Сборка

```bash
python3 tools/site/build_site.py   # запускает tools/dezinfektsiya/build_page.py, затем меню, подвал, бегущую строку, «Смотрите также», sitemap
python3 tools/site/build_prod.py   # версия для Timeweb со счётчиками (dist/timeweb/dezinfektsiya/index.php)
```

- `build_page.py` берёт оболочку (head, шапка, подвал, плавающие кнопки, подключение скриптов) из `dezinsektsiya/index.html`
  и заменяет мета-теги, предзагрузку фото первого экрана, разметку schema.org (BreadcrumbList, WebPage с датой обновления,
  Service с OfferCatalog из 8 услуг (в том числе «Микробиологические смывы и лабораторный контроль») и AggregateOffer, FAQPage из 12 вопросов), стили страницы и `<main>`.
- `main.html` — содержимое страницы. Заготовки: `{{faq:0-5}}`, `{{faq:6-11}}` (вопросы — список `FAQ` в `build_page.py`),
  `{{ico:lucide-…}}` (иконки из `tools/site/icons.json` и трёх добавленных в `build_page.py`: building-2, wind, bug).
- `extra.css` — стили блоков этой страницы (классы `dzf-*`).
- `page.js` — фон блока заявки, предпросмотр без отправки заявки вне рабочего домена, сбор полей формы в `msg`
  (send.php читает только `name`, `company`, `phone`, `email`, `type`, `msg`; тип объекта — значение из списка `send.php`,
  выбранная задача, комментарий и адрес страницы — в `msg`).
- Типографика: неразрывные пробелы (`tools/legal/typo.py`); шифры документов вместе с «СП», «СанПиН», «МР», «Р»
  и номер лицензии не разрываются переносом (`span.nw`). Телефон +7 (495) 104-35-70 — в том же виде, что на остальных
  страницах, его подменяет колл-трекинг UIS.
- Меню: `tools/menu/apply_menu.py` (список `USLUGI`, первый пункт). Перелинковка и «Смотрите также»: `tools/site/unify.py`
  (ключ `dezinf`; связанные — вентиляция, санитарный аудит, дезинсекция, дератизация).

## Блоки

Первый экран → «Что такое дезинфекция» (определение по п. 40 СанПиН 3.3686-21, таблица «дезинфекция / дезинсекция /
дератизация», дата обновления и проверки норм) → все услуги (8 карточек) → почему «дезинфекция» — весь комплекс (пп. 79–80)
→ виды профилактической дезинфекции (плановая, генеральная в санитарный день, внеплановая; «Плановая дезинфекция:
как работаем», `#kak-rabotaem`) → методы и средства (с карточкой «Лабораторный контроль», `#kontrol`) → периодичность по правилам с 01.09.2026 (10 типов объектов) → вентиляция → санитарный аудит → пест-контроль по IPM
→ документы → отрасли → стоимость → «Смотрите также» → 12 вопросов → нормативная база → заявка.

## Нормы, на которые ссылается страница (проверено 06.11.2026)

- СанПиН 3.3686-21: пп. 40, 41 (цель и виды дезинфекции), 79–80 (дезинфекционная деятельность), 84–89 (средства, хранение,
  кто проводит), 131 (транспорт), 132 (вентиляция и кондиционирование: дезинфекция не реже 1 раза в год, легионеллы — 2 раза в год).
- Шесть правил, действующих с 01.09.2026: СП 2.1.4284-26 (вместо СП 2.1.3678-20), СП 2.3.6.4281-26 (вместо СП 2.3.6.3668-20),
  СанПиН 2.3/2.4.4282-26 (вместо СанПиН 2.3/2.4.3590-20), СП 2.2.4285-26, СП 2.4.2.4283-26, СП 2.5.4286-26.
- Постановление Правительства РФ от 20.03.2024 № 337 — лицензирование услуг по дезинфекции, дезинсекции и дератизации с 01.03.2025.
- МР 3.5.0353-24 (санитарная обработка на пищевых предприятиях), МР 3.5.0396-25 (вентиляция), Р 3.5.1.4025-24 (УФ-обеззараживание),
  Р 4.2.3676-20 (испытания дезсредств), ТР ТС 021/2011 ст. 10, 52-ФЗ ст. 11 и 32.
