## Как пересобрать

```
python3 tools/food/assemble.py      # только если менялась пищевая страница: она собирается из шаблона и затирает меню
python3 tools/menu/apply_menu.py    # меню на все страницы; можно запускать повторно
python3 tools/build.py              # встраивает style.css в index.html и собирает app.min.js
```

- Разметку меню задаёт только `apply_menu.py` (списки `INDUSTRIES`, `DOGOVOR`, `MATERIALS`, `SERVICE` в начале файла). Стили — в `style.css` (`.nav-dd`, `.mm-group`, `.ft`), поведение — в `app.js` (разделы «меню» и «активный пункт меню»).
- В подписях стоят неразрывные пробелы после коротких слов («и отели», «на дератизацию») — скрипт берёт правила из `tools/legal/typo.py`, как в остальных текстах сайта. Слова через дефис в подписях подвала не переносятся (`<span class="nw">`). На телефоне ссылки подвала — `inline-flex`, поэтому такая подпись целиком обёрнута ещё в один `<span>`, иначе пропадает пробел перед вложенным тегом. Скрипт делает это сам.
- После правки `style.css` или `app.js` поднимите `?v=` на всех страницах, которые их подключают. Сейчас: `style.css?v=20261106a` (договор, пищевое производство; у страницы «Пест-менеджмент или разовая обработка» пока `20261030m` — поднять при её выкладке), `app.min.js?v=20261030m`. Главная встраивает стили сама (`tools/build.py`).

В ветку отдельным коммитом добавлена и правка шапки для экранов 320–400 px из файлов проекта («Главная — шапка на узких телефонах», тоже не выложена): без неё кнопка меню на 320–375 px уходит за правый край, и мобильное меню нельзя нормально проверить. ## Выкладка (когда будет разрешена)

- Сначала `app.min.js` (и `style.css` для внутренних страниц), затем страницы. Прежний `app.min.js` с новой разметкой не работает: он ищет на странице блок по адресу каждой ссылки меню, на ссылке `pishchevoe-proizvodstvo/` падает с ошибкой, и дальше не работают вопросы, форма и анимации. Если страницу загрузить раньше скрипта, посетители получат прежний скрипт по новому адресу `?v=20261030m`, и сервер закэширует его на год.
- Счётчики не менялись: блок `server/counters.html` (Метрика 113675622, UIS, Radist) по-прежнему вставляется перед `</body>` при выкладке каждой страницы как `index.php`; в HTML репозитория счётчиков нет. Телефон `+7 (495) 104-35-70`, ссылки Telegram и MAX и кнопки заявки остались прежними.
