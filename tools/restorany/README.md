## Форма заявки

`send.php` читает только `name`, `company`, `phone`, `email`, `type`, `msg`. Поэтому формат заведения, задача и адрес с комментарием перед отправкой складываются в поле `msg` (скрипт в конце страницы), `type` = «Ресторан или кафе». На GitHub Pages форма работает в демо-режиме и ничего не отправляет (заглушка срабатывает вне домена пестконтроль-центр.рф).
