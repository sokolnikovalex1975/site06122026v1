# Дезинфекция: проверка выравнивания блока

Проверена [публичная страница GitHub Pages](https://sokolnikovalex1975.github.io/site06122026v1/dezinfektsiya/) после [исправления 5f7c626](https://github.com/sokolnikovalex1975/site06122026v1/commit/5f7c626644653c7029661004471312aa16b02e5c). Проверка выполнена 11.11.2026.

## Изменение

- **Причина:** вводный абзац находился в `.head` над двухколоночным блоком, оставляя пустоту над таблицей справа.
- **Исправление:** абзац перенесён в начало `.dzf-why-t`. Существующая сетка выравнивает текст и таблицу по верхнему краю.
- **Исходник:** аналогичное изменение внесено в `tools/dezinfektsiya/main.html`, чтобы последующая сборка не вернула дефект.
- **Границы:** Timeweb не изменялся; только GitHub-превью. Общие CSS/JS, контакты, форма, коды аналитики и колл-трекинга не изменялись.

## Проверки интерфейса

- **1430 px:** разница верхних координат левой колонки и таблицы 0 px; горизонтального переполнения нет.
- **768 и 375 px:** одна колонка, все три абзаца идут перед таблицей; горизонтального переполнения нет.
- **Смена ширины:** 1430 → 768 → 375 → 1430; двухколоночное выравнивание восстанавливается.
- **Навигация:** ссылка «Плановая и внеплановая дезинфекция» прокручивает к видам; «Дезинсекция» открывает соответствующую страницу.
- **FAQ:** вопрос открывается и закрывается; `aria-expanded` меняется на `true` и обратно на `false`.
- **Форма:** CTA открывает раздел заявки; имя, телефон, тип объекта и задача доступны для ввода. Отправка заявки намеренно не выполнялась.
- **Поиск:** запрос «дезинфекция» показывает результаты; Escape закрывает поиск.
- **Мобильное меню:** открывается и закрывается на 375 px; `aria-expanded` корректен.
- **Без JavaScript:** текст и таблица доступны.
- **Консоль:** ошибок JavaScript при проверке изменённой страницы не зафиксировано.
- **Интеграции:** `python3 tools/site/tracking_laws.py --check` проходит; сухая production-сборка проходит; `--check-prod dist/timeweb/dezinfektsiya/index.php` проходит. Проверка реальной подмены UIS не проводилась: изменения счётчиков или разметки телефона отсутствуют, Timeweb не затронут.
