# Блок «Что видит камера в коробе» — реалистичные кадры с анимацией (превью 14.11.2026)

Страница: `/ochistka-dezinfektsiya-ventilyatsii/`, раздел «Видеоинспекция», блок `#vduct`.
Превью (только GitHub Pages, noindex, без счётчиков): `/preview-kamera-ventilyatsii/#video`.
**На Timeweb не выложено, исходники страницы (`main.html`, `extra.css`, `page.js`) не менялись — ждёт команды владельца.**

## Что меняется

Запрос владельца 13.11.2026: вместо нарисованной схемы — «по-настоящему»: три кадра одного участка короба,
которые просто меняются — было → промежуток → стало.

- SVG-схема заменена тремя фото одного и того же участка прямоугольного воздуховода: «До работ» (пыль, пух,
  жировые подтёки, плесень у фланца, паутина) → «После очистки» (металл чистый, у фланца остались пятна плесени)
  → «После дезинфекции» (чистый сухой металл).
- Смена кадров — WebGL-шейдер поверх фото: щётка уходит вглубь короба (граница чистого металла идёт по сечению
  короба с перспективой), поднимает клубы пыли и пылинки; затем туман дезсредства приходит из глубины, накрывает
  участок, под ним кадр меняется, туман оседает. К началу — через затемнение.
- Пока кадр на экране, состояния меняются сами по кругу (2,6 с · 3,4 с щётка · 2,4 с · 3,6 с туман · 3,2 с ·
  1,1 с), на активной кнопке — тонкая полоска времени. Кнопка в углу кадра — пауза/пуск; щелчок по состоянию —
  остановка на нём. Кадр ушёл с экрана или вкладка скрыта — ничего не считается.
- «Уменьшить движение» — сами не меняются, переходы без эффектов. Без WebGL — плавная смена фото (CSS).
- Подпись над кадром: «Иллюстрация · что видит камера в коробе» (было «Схема · …»); на каждом кадре метка
  «ИЛЛЮСТРАЦИЯ» — кадры не съёмка конкретного объекта и не выдаются за неё.
- Обозначения — «Что видно на кадре»: убранное по состоянию отмечается зелёной галочкой и зачёркивается
  (для экранного диктора — «— убрано»).
- Подписи трёх состояний лежат в одной ячейке сетки — высота блока не меняется при смене (нет сдвига страницы, CLS 0).
- Тексты подписей, кнопки, остальная страница, формы, Метрика 113675622, UIS, Radist, телефон и почта — без изменений.

## Как выложить после согласования

1. Перенести блок в исходники страницы: `main.html` (подпись, `art.html`, `legend.html`), `extra.css` (`block.css`
   вместо стилей схемы), `page.js` (`block.js` вместо скрипта схемы), собрать `build_page.py` → `build_site.py`.
2. Для Timeweb — правкой файла с сайта: `apply.py index.php <новый index.php>` (меню на сайте может отличаться
   от репозитория), выгрузить 9 файлов `img/vent-kadr-*.webp` и страницу, сверить SHA-256, проверить счётчики и
   подмену номера UIS, отправить адрес в IndexNow.
