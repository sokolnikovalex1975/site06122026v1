# «Дезинфекция автотранспорта» — /dezinfektsiya/avtotransport/

Страница услуги для перевозчиков и автопарков (20.11.2026, превью GitHub Pages, на Timeweb — только по отдельной команде
владельца). Подпункт «Дезинфекции для организаций» в меню «Услуги» шапки, мобильного меню и подвала.

## Файлы

- `main.html` — содержимое `<main>`: метки `@/` (корень сайта), `{{a:ключ|текст}}` (ссылки на нормы), `{{ico:…}}` (иконки),
  `{{faq:…}}` (вопросы из `build_page.py`);
- `build_page.py` — страница из оболочки `dezinsektsiya/index.html`: title, description, canonical, Open Graph, JSON-LD
  (BreadcrumbList, WebPage с автором, Service, 2 DigitalDocument, FAQPage на 12 вопросов), стили и скрипт страницы;
- `extra.css`, `page.js` — стили и поведение (схема зон, самопроверка, цели Метрики `avto_akt_obrazets` и `avto_akt_blank`);
- `build_akt.py` — образец и бланк акта АДТ-01 в PDF (`dezinfektsiya/avtotransport/*.pdf`) и превью `img/avto-akt-obrazets-*.webp`;
- `make_images.py` — фото первого экрана и картинка Open Graph из мастер-файла (файлы проекта «Страница Дезинфекция
  автотранспорта/Изображения (мастер)», с 22.11.2026 — `avto-hero-master-v6.png`, вариант 6: машина на три четверти
  сзади, мастер в кузове справа); иконка «Все услуги» `img/ig-avtotransport-*.webp` — из мастер-файла
  «Инфографика в стиле лаборатории/v2 — внедрение/Мастер-файлы 2048/avtotransport.png»;
- `rebuild_in_copy.sh` — пересборка страницы со всеми шагами сборки в копии репозитория; блоки `<head>` выравниваются по «Дезинсекции»,
  затем `zayavka.transform` ставит стили и скрипты «Состава заявки» перед `tel-plain`, как на остальных страницах.

## Сборка

```
python3 tools/avtotransport/build_akt.py      # PDF и превью акта (нужны playwright, PyMuPDF, fontTools с brotli)
bash tools/avtotransport/rebuild_in_copy.sh   # страница со всеми шагами сборки; в репозиторий — только она
python3 tools/search/build_index.py           # поиск по сайту
python3 tools/site/build_prod.py              # пакет для Timeweb со счётчиками (выкладка — только по команде владельца)
```

Почему не `tools/site/build_site.py`: полная сборка сейчас останавливается на `tools/sklady/assemble.py` и
`tools/bctc/build_page.py` (в шаблоне больше нет блока мессенджеров), а повторный прогон шагов по готовым страницам
переставляет блоки `<style>` в `<head>`. Поэтому 20.11.2026 на остальных страницах изменены только нужные места:
пункт меню (шапка, мобильное меню, подвал), строка в «Все услуги», «Смотрите также» и ссылки в тексте на страницах
«Дезинфекция для организаций» и «Склады и логистика». Порядок блоков `<head>` на них не менялся.
