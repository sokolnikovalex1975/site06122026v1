Сверено с `server/counters.html` и `app.js` 06.11.2026. В самой странице счётчиков нет: на сайте их вставляет сервер одним блоком `server/counters.html` перед `</body>`; этот файл при правках не меняется.

## Проверка вёрстки и текста 06.11.2026 (после замечания по мобильной версии)

**Вёрстка**
- Карточки «Насекомые, которых мы устраняем»: у блока `.pest-top` (фото + название) не было стилей, поэтому карточка `.pest` (flex в строку из `style.css`)
  ставила фото с названием и описание рядом — на телефоне описание сжималось до колонки 10–30 px по слову в строке. Добавлены правила
  как на странице фармацевтики: `.pests .pest{flex-direction:column}`, `.pest-top{display:flex}` и отступы; пустой `.pest-scan` скрыт.
- Хлебные крошки на телефоне — 12 px вместо 10–11 px (в одну строку, под первым экраном на 393×852).
- Надзаголовок первого экрана на компьютере не оставляет «ЛИЦ» отдельной строкой: «Контроль насекомых по IPM · Только для юридических лиц»,
  перенос только после «·».
- Самопроверка начинается с «0 из 5» и пустых отметок (как на страницах магазинов, ресторанов и гостиниц), а не с заранее отмеченных 5 из 5.
