# Санитарный навигатор — сборка раздела /normativnaya-baza/

Генератор собирает объединённый раздел: прежняя «Нормативная база» + справочная система по санитарному
законодательству. Исходные страницы сайта в репозитории генератор не меняет — результат пишется в `dist/`
(папка в `.gitignore`).

## Запуск

```
node tools/navigator/build.js            # dist/navigator-preview — копия сайта с новым разделом
node tools/navigator/build.js --hosted   # dist/navigator-hosted — то же для закрытого предпросмотра
```

Нужен только Node.js (18+), пакеты не требуются.

Режим `--hosted` отличается только тремя вещами, которые нужны хостингу предпросмотра:
ссылки на папки дописаны до `index.html`, хранилище браузера заменено памятью вкладки, служебные папки
`preview-*` и `404.html` не копируются. Для GitHub Pages и Timeweb этот режим не нужен.

## Что получается

| Адрес | Что это | Страниц |
|---|---|---|
| `/normativnaya-baza/` | главная навигатора: поиск, четыре входа, роли, объекты, темы, разборы, изменения | 1 |
| `/normativnaya-baza/obekty/…` | объекты: 37 проверочных листов и 4 подборки | 42 |
| `/normativnaya-baza/temy/…` | 17 тем; «Насекомые и грызуны» — прежний текст хаба без изменений + вопросы листов | 18 |
| `/normativnaya-baza/voprosy/…` | разборы: 12 новых; три прежние страницы раздела остаются на своих адресах и стоят в списке | 13 |
| `/normativnaya-baza/dokumenty/…` | реестр и паспорта 205 документов | 206 |
| `/normativnaya-baza/kalendar/`, `/periodichnost/` | календарь изменений и график работ | 2 |
| `/normativnaya-baza/poisk/`, `/o-razdele/` | поиск по навигатору и описание метода | 2 |

Список всех страниц с Title, H1 и пометкой «открывать ли для индексации» — `pages.json` (обновляется при сборке).

## Откуда что берётся

- `data/core.js`, `data/q.js` — данные: листы, вопросы, документы, разборы, события. Собираются отдельным
  конвейером (файлы проекта → «Нормативная библиотека / Санитарный навигатор — исходники»).
- `lib/data.js` — загрузка данных и адреса страниц (объекты, темы и разборы — вручную, документы — транслитерацией).
- `lib/render.js` — разметка блоков. Классы пишутся без приставки, `build.js` добавляет `nv-`.
- `lib/css.js` — `nv.css` = `src/prototype.css` (приставка `nv-`, область `.nv`) + `src/extra.css`.
- `src/nv.js` — поведение страниц: отметки, группировка, отбор, выгрузка. `src/nv-search.js` — поиск.
- Шапка, меню, «Все услуги», заявка и подвал берутся из `normativnaya-baza/index.html` как есть.

## Правила, которые зашиты в сборку

- Название раздела — константа `NAME` в `build.js`. В копии сайта оно заменяет «Нормативная база» в меню, подвале
  и цепочках; исходные страницы не правятся.
- Крошки — вверху первого экрана над H1 (класс сайта `f-crumbs`, ниже 900 px скрыты), разметка BreadcrumbList есть.
- «Смотрите также» — перед вопросами; «Все услуги» — перед заявкой; открыт только первый вопрос.
- На странице одна ссылка на подходящую услугу (панель «Нужна помощь»).
- Счётчиков в страницах нет; телефон и почта — из обвязки сайта. Проверка теми же правилами, что и
  `tools/site/build_prod.py` (`tracking_laws`, `independence_law`), проходит без нарушений.
- Метки «Норма» и «Практика»; непроверенные врачом части подписаны прямо на страницах.

## Чего генератор пока не делает

- Не добавляет страницы в `PAGES` (`tools/site/build_prod.py`, `tools/menu/apply_menu.py`, `tools/search/build_index.py`)
  и в `sitemap.xml` — это шаг выкладки, он делается по отдельной команде.
- Не переименовывает раздел в исходных страницах сайта.
- Не ставит редирект: прежний адрес хаба остаётся, его текст переезжает на страницу темы.
