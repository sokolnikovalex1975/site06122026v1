# Страница «Пест-контроль фармацевтического производства» — `/farmatsevticheskie-proizvodstva/`

Отраслевая B2B-страница из меню «Отрасли ▾ → Фармацевтические производства». В сайте site06122026v1 — с 06.11.2026; превью на GitHub Pages закрыто от индексации.

- **H1:** «Пест-контроль фармацевтического производства по GMP»
- **Title:** «Пест-контроль фармацевтического производства по GMP — ПЕСТКОНТРОЛЬ Центр»
- **Description:** «Пест-контроль фармпроизводств и складов лекарств в Москве и МО по GMP ЕАЭС: контуры защиты до чистых зон, без яда в помещениях, тренды и документы для инспекции.»
- **Запросы в заголовках H2:** пест-контроль на фармацевтическом предприятии, пест-контроль чистых помещений, дератизация и дезинсекция фармацевтического производства, документы по пест-контролю для GMP-инспекции, программа пест-контроля, сколько стоит пест-контроль фармацевтического производства, пест-контроль по GMP.

## Блоки

1. Первый экран: хлебные крошки, H1, три тезиса, короткий лид, кнопки «Заказать бесплатное обследование» и телефон.
2. Самопроверка «Проверьте пест-контроль перед инспекцией»: 5 пунктов и счётчик «N из 5».
3. «Что такое пест-контроль на фармацевтическом предприятии»: определение для быстрых ответов ИИ-чатов, три принципа, фото «специалист + отдел качества», 4 карточки норм (GMP ЕАЭС п. 3.4, 4.29, часть II п. 4.72; GDP ЕАЭС п. 36), источники.
4. «Шесть контуров защиты»: интерактивная SVG-схема (кольца подсвечиваются при наведении или нажатии) и список зон от периметра до чистых помещений D→A.
5. «Дератизация и дезинсекция фармацевтического производства»: 6 групп вредителей, в том числе хлебный точильщик и табачный жук (ссылка на ОФС.1.5.3.0002).
6. «Документы по пест-контролю для GMP-инспекции и аудита»: таблица «Что спросят → Что показываете», образец программы (PDF) и ссылка на журнал.
7. «Насекомое в чистой зоне: что происходит дальше»: 5 шагов (находка → вид → путь проникновения → корректирующие действия → запись для CAPA) и блок «Почему не обрабатываем чистую зону».
8. Регламент из 5 шагов, внеплановый выезд за 3 часа, ссылка на договор.
9. «Пест-контроль фармпредприятий разного профиля»: ТЛФ, стерильные, АФС, фитопрепараты, склады и дистрибьюторы.
10. «Когда пора менять подход к пест-контролю»: 4 типовые ситуации.
11. Стоимость: что влияет на расчёт, что входит, условия (0 ₽ за обследование, без наценки за ночь и выходные, НДС и ЭДО). Цифр «от … ₽» нет: прайс для фармы не согласован.
12. FAQ: 10 вопросов, они же в разметке `FAQPage`.
13. Форма заявки: тип объекта «Фармацевтическое производство» (значение уже есть в списке `send.php`), профиль производства, ближайшая проверка, адрес. Профиль и проверка упаковываются в поле `msg`.

Нормы сверены по первоисточникам: [Правила GMP ЕАЭС, Решение Совета ЕЭК № 77](https://docs.cntd.ru/document/456026099), [Правила GDP ЕАЭС, Решение Совета ЕЭК № 80](https://www.consultant.ru/document/cons_doc_LAW_207404/), [СанПиН 3.3686-21](http://pravo.gov.ru/proxy/ips/?docbody=&nd=602107773&rdk=0) (п. 101 — кратность обследований), [ОФС.1.5.3.0002](https://base.garant.ru/412600623/) (заражённость сырья вредителями запасов). Лицензия: № Л064-00111-77/01942445.

## Сборка

```bash
python3 tools/farma/assemble.py      # farmatsevticheskie-proizvodstva/index.html (превью, noindex)
python3 tools/site/build_site.py     # анимации в стиле главной, бегущая строка, «Смотрите также», меню и подвал, sitemap
python3 tools/site/build_prod.py     # версия для Timeweb: index.php со счётчиками, без noindex
```

В `tools/site/unify.py` у страницы свои пункты бегущей строки и «Смотрите также» (дератизация, дезинсекция, программа, журнал),
в `tools/menu/apply_menu.py` пункт «Фармацевтические производства» ведёт на эту страницу, на главной ссылка — в карточке отрасли.

- Шаблон (шапка, подвал, форма, общий JS) — текущая страница договора, копия в `template-dogovor.html`.
- `main.html` — содержимое `<main>`, `extra.css` — стили страницы (встраиваются в `<style>`), SVG-схема контуров рисуется в `assemble.py` (`kontur_svg`).
- Типографика — `tools/legal/typo.py`. Дефисные слова («пест-контроль», «GMP-инспекции») не переносятся только в заголовках и вопросах FAQ. Номер `+7 (495) 104-35-70` остаётся в том же виде, что на остальных страницах: по нему номер подменяет колл-трекинг UIS.
