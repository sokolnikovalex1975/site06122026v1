# Вопросы внизу страницы — развёрнут только первый

Запрос владельца 13.11.2026 в [диалоге задачи](https://www.perplexity.ai/computer/tasks/9a0cd82a-bc50-4294-b310-14213eb74082): на странице «Схема точек пест-контроля» «сразу развёрнуты вопросы в самом низу страницы… должен быть развёрнут только первый вопрос; все остальные должны быть свёрнуты»; проверить все страницы сайта и показать превью.

## Что было

Проверка рабочего сайта в браузере (`tools/qa/faq_first_test.mjs`, 39 страниц с вопросами из sitemap, компьютер 1440 и телефон 390, счётчики заблокированы): на 7 страницах при открытии развёрнуты все вопросы, на остальных 32 — только первый.

| Страница | Вопросов |
|---|---|
| `/materialy/skhema-tochek-pest-kontrolya/` | 7 |
| `/materialy/akt-deratizatsii-i-dezinsektsii/` | 10 |
| `/deratizatsiya-i-dezinsektsiya/` | 7 |
| `/dezinsektsiya/restorany-i-kafe/` | 10 |
| `/deratizatsiya/restorany-i-kafe/` | 9 |
| `/normativnaya-baza/dokumenty-dlya-rospotrebnadzora/` | 10 |
| `/normativnaya-baza/effektivnost-deratizatsii-i-dezinsektsii/` | 8 |

Причина: генераторы этих страниц ставили всем вопросам `class="card qa open"` и `aria-expanded="true"` (`tools/normativnaya-baza/build_pages.py` с `faq_open` — общий для нормативной базы, акта и схемы точек; `tools/restorany-uslugi/build_pages.py`; `tools/deratizatsiya-i-dezinsektsiya/build_page.py`). `app.js` при загрузке раскрывает первый вопрос, остальные не сворачивает.

## Что сделано

- У вопросов 2…N убраны класс `open` и `aria-expanded="true"` → `"false"`: 54 вопроса на 7 страницах. Тексты, ответы, разметка FAQPage, стили, скрипты, счётчики, телефон и почта не менялись. Ответы остаются в коде страницы — роботы и ИИ-ассистенты читают их и в свёрнутом виде.
- `tools/site/faq_first.py` — шаг сборки (после `flex_text.py`) и точечная правка готовых страниц: `--check` (репозиторий), `--check-prod` (пакет выкладки).
- Генераторы исправлены так же; полная сборка в копии репозитория даёт на этих 7 страницах ту же разметку вопросов.

- GitHub-версия локально — 40 страниц × 2 экрана, 0 нарушений: первый вопрос открыт, остальные свёрнуты, второй раскрывается и сворачивается щелчком (касанием), ошибок JavaScript нет.
- Рабочий сайт до правки — 14 нарушений (7 страниц × 2 экрана); с подменой 7 страниц пакета — 14/14 без нарушений.
- Превью: GitHub Pages по коммиту `f883c32`; снимки блока «Вопросы» (компьютер и телефон) — в файлах проекта, папка «Вопросы внизу страниц — развёрнут только первый».

## Пакет для Timeweb

`python3 tools/deploy/prepare-2026-11-13-faq-first.py <новая папка>` снимает все страницы sitemap рабочего сайта по HTTPS и правит только страницы, где при загрузке открыт не только первый вопрос (в GitHub есть ещё не опубликованные правки других задач — они в пакет не попадают). Для каждой страницы проверено: замены — только карточки вопросов `<div class="card qa open"><button aria-expanded="true" aria-controls="aN" id="qN">`, каждая ровно один раз; обратная замена даёт исходник байт в байт; результат совпадает с `faq_first.patch`; закон о счётчиках и контактах (`tracking_laws.check_page`) и закон независимости — до и после.

Пакет — `tools/deploy/faq-first-2026-11-13/` (deploy_payload.json, MANIFEST.txt; снят с сайта 13.11.2026 после выкладки title главной), серверный скрипт — `tools/deploy/publish_faq_first.py` (Python 3.6, без f-строк): `--check`, `--publish`, `--rollback`. Скрипт проверен на копии `public_html`: проверка, выкладка 7/7, повтор (`ALREADY PUBLISHED`), откат 7/7, отказ при чужом изменении файла.

## Публикация на рабочем сайте

Не выполнялась — ждёт команды владельца. Если до выкладки какая-либо из 7 страниц изменится на сайте, скрипт откажет (`CURRENT FILE CHANGED`) — пакет нужно собрать заново.
