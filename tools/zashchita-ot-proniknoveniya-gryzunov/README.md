- Самостоятельные title, description, canonical и Open Graph; HTML читается без JavaScript.
- Перелинковка: новая карточка в `preview-services/`, контекстная ссылка в дератизации, обратные ссылки на дератизацию, отрасли, программу и журнал, аудит и нормативную базу.
