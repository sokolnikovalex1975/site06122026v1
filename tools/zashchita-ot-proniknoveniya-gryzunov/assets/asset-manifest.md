# Ресурсы страницы «Защита от проникновения грызунов»

Страница расширяет существующий сайт без изменения дизайна. Используется его текущая система: чёрный фон `#000000`, текст `#ffffff` / `#9f9fa9`, акцент `#7c86ff`, шрифт Inter, тонкие заголовки с курсивным акцентом, существующие скруглённые кнопки и карточки. Ближайшее направление из дизайн-справочника: cinematic-tech, но правила существующего сайта имеют приоритет.

## Источник оформления

- Страница дератизации: https://xn----itbbsflddbfpfdodg9d0f.xn--p1ai/deratizatsiya/
- Логотип, шапка, мобильное меню, подвал, формы, юридические ссылки и мессенджеры берутся из её актуального HTML.
- Общий файл `style.css` не изменяется.

## Шрифты

Inter, локальные variable woff2 для обычного и курсивного начертания. Используются имеющиеся `fonts/inter-ru-wght-normal.woff2` и `fonts/inter-ru-wght-italic.woff2`; новые семейства и внешние CDN не добавляются.
