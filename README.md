### Хлебные крошки на телефоне (правило владельца для всех страниц и будущих проектов)

в пакетах, собранных правкой страниц с сайта, оставляйте эту строку. На сайте правило выложено 06.11.2026 в 16:45 МСК на все 17 страниц

## Сборка

```
python3 tools/site/build_site.py
```

Шаги: `tools/site/unify.py` (анимации, заголовки, бегущая строка, перелинковка) → `tools/site/legal_pages.py`
(шапка и подвал на страницах документов) → `tools/menu/apply_menu.py` (меню и подвал) → `tools/build.py`
(сжатие `app.js` → `app.min.js`, встраивание `style.css` в главную) → `tools/search/build_index.py` (индекс поиска
`search-index.json` и `search.min.js`) → `server/sitemap.xml`. Повторный запуск ничего не дублирует.
Нужны Python 3 и Node.js (`npx esbuild`).

Исходники для правок: `style.css`, `app.js`, HTML страниц. Генераторы отдельных страниц (`tools/food/`, `tools/dezinsektsiya/`, `tools/farma/`,
`tools/magaziny-i-torgovye-seti/`, `tools/zhurnal/`, `tools/build_programma.py`, `tools/ppk/build_ppk.py`) — после них снова запустите `tools/site/build_site.py`.

внизу): правки 09.11.2026 в нём повторены, но страницу правьте в `materialy/programma-pest-kontrolya/index.html`, а генератор
без сверки `git diff` не запускайте — он откатит поздние правки.

### Выкладка на Timeweb

Песочница Perplexity к FTP Timeweb не подключается, поэтому `tools/deploy/run_all.sh` запускается в «Терминале» на Mac mini.
Рядом со скриптом — `pkg/` (содержимое `dist/timeweb/`), `MANIFEST.sha256`, `deploy.conf` (пример —
`tools/deploy/deploy-2026-11-06-site06122026v1.conf`) и временный `.netrc` с доступом FTP; без `deploy.conf` скрипт не запускается.

- `deploy` — копия заменяемых файлов и сверка с `EXPECTED_BEFORE` (если на сервере не те файлы — выкладка отменяется, прежняя копия не трогается),
  загрузка новых файлов, затем заменяемых, сверка всех файлов на сервере с пакетом; при ошибке — откат. В конце `.netrc` удаляется.
- `rollback` — вернуть заменённые файлы из `backup/`. `check` — подключение и список файлов.
- Timeweb не принимает частые подключения, поэтому файлы передаются пакетами — одно подключение FTP на этап.
- Копия, журнал, скрипт и `deploy.conf` сохраняются в `~/<NAME>` на Mac.
- Счётчики (с 08.11.2026): перед загрузкой `run_all.sh` проверяет каждую страницу пакета (`*index.php`, кроме политики
  и согласия) — ровно один блок «Метрика 113675622 + UIS + Radist», у заменяемых страниц байт в байт как в копии
  с сервера. Если нет — выкладка останавливается до загрузки (код 19). Намеренная правка счётчиков —
  `ALLOW_COUNTERS_CHANGE=1 bash run_all.sh deploy`. Без подключения: `bash run_all.sh counters`.
