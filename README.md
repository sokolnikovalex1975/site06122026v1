Основа — репозиторий `pestcontrol-center-menu-V1-30102026`, коммит `6191f02` (все правки страниц на 06.11.2026).

не отправляют, счётчиков нет. Рабочий сайт на Timeweb этой сборкой не заменён — выкладка отдельным решением.

## Единый стиль

- На всех страницах — анимации главной (GSAP + ScrollTrigger + Lenis, локальные файлы `vendor/`):
  заставка (один раз за посещение), курсор, зерно, полоса прогресса, плавная прокрутка, бегущая строка после первого экрана,
  заголовки H2 по словам, надзаголовки с линией, проявление блоков, группы карточек, «магнитные» кнопки,
  наклон карточек с фото, свечение и параллакс в блоке заявки, появление подвала.
- Первый экран внутренних страниц входит как на главной: строки H1 поднимаются из-под маски, затем цепочка,
  отметки, текст и кнопки.
- Заголовки — как на главной: тонкое начертание (300), плотная разрядка, акцент курсивом 500;
  на телефонах H1 и H2 внутренних страниц одного размера.
- При `prefers-reduced-motion` и без JavaScript всё показывается сразу, без анимаций.

## Скорость

## Сборка

```
python3 tools/site/build_site.py
```

Шаги: `tools/site/unify.py` (анимации, заголовки, бегущая строка, перелинковка) → `tools/site/legal_pages.py`
(шапка и подвал на страницах документов) → `tools/menu/apply_menu.py` (меню и подвал) → `tools/build.py`
(сжатие `app.js` → `app.min.js`, встраивание `style.css` в главную) → `server/sitemap.xml`. Повторный запуск ничего не дублирует.
Нужны Python 3 и Node.js (`npx esbuild`).

Исходники для правок: `style.css`, `app.js`, HTML страниц. Генераторы отдельных страниц (`tools/food/`, `tools/dezinsektsiya/`,
`tools/zhurnal/`, `tools/build_programma.py`) — после них снова запустите `tools/site/build_site.py`.

## Счётчики и колл-трекинг

Блок счётчиков хранится в `server/counters.html` и совпадает с рабочей главной байт в байт:
Яндекс Метрика `113675622` (Вебвизор, карта кликов, точный показатель отказов), колл-трекинг UIS с подменой номера
и ожиданием подмены при нажатии на телефон, Radist (код заявки в ссылках Telegram и MAX). Цель Метрики `audit`
и офлайн-заявка UIS отправляются из `app.js` после успешной отправки формы.

Версия для Timeweb со счётчиками на всех 9 страницах:

```
python3 tools/site/build_prod.py      # → dist/timeweb/ (в репозиторий не попадает)
```

Каждая страница — `index.php` с блоком счётчиков перед `</body>`, без метки `noindex`; политика и согласие —
`noindex, follow` и без счётчиков, как сейчас на сайте. `send.php` в пакет не входит: на сервере он с настоящим паролем почты.
Если в папке страницы на сервере лежит `index.html`, его нужно убрать, чтобы сервер отдавал `index.php`.
