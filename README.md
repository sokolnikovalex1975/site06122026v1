## Сборка

```
python3 tools/site/build_site.py
```

Шаги: `tools/site/unify.py` (анимации, заголовки, бегущая строка, перелинковка) → `tools/site/legal_pages.py`
(шапка и подвал на страницах документов) → `tools/menu/apply_menu.py` (меню и подвал) → `tools/build.py`
(сжатие `app.js` → `app.min.js`, встраивание `style.css` в главную) → `server/sitemap.xml`. Повторный запуск ничего не дублирует.
Нужны Python 3 и Node.js (`npx esbuild`).

Исходники для правок: `style.css`, `app.js`, HTML страниц. Генераторы отдельных страниц (`tools/food/`, `tools/dezinsektsiya/`, `tools/farma/`,
`tools/magaziny-i-torgovye-seti/`, `tools/zhurnal/`, `tools/build_programma.py`, `tools/ppk/build_ppk.py`) — после них снова запустите `tools/site/build_site.py`.
Страницы гостиниц, санитарного аудита и складов (`tools/sklady/assemble.py`) `build_site.py` собирает сам.

Страница «Пест-контроль для складов и логистики»: текст и разметка — `tools/sklady/main.html`, свои стили — `extra.css`, скрипт
(схема зон склада, самопроверка, текст заявки) — `page.js`; `assemble.py` собирает страницу на шаблоне страницы дератизации
(Schema.org: BreadcrumbList, Service с ценами, FAQPage). Подробности, счётчики и проверка — `tools/sklady/README.md`.

Страница «Магазины и торговые сети»: текст и разметка — `tools/magaziny-i-torgovye-seti/main.html`, свои стили — `own.css`.
`make_css.py` собирает `extra.css` (общие блоки внутренних страниц + карта зон + `own.css`), `assemble.py` собирает страницу
на шаблоне страницы договора (шапка, подвал, Schema.org: WebPage, BreadcrumbList, Service с ценами, FAQPage).

## Счётчики и колл-трекинг

Блок счётчиков хранится в `server/counters.html` и совпадает с рабочей главной байт в байт:
Яндекс Метрика `113675622` (Вебвизор, карта кликов, точный показатель отказов), колл-трекинг UIS с подменой номера

и офлайн-заявка UIS отправляются из `app.js` после успешной отправки формы.

Версия для Timeweb со счётчиками на всех 10 страницах:

```
python3 tools/site/build_prod.py      # → dist/timeweb/ (в репозиторий не попадает)
```

Каждая страница — `index.php` с блоком счётчиков перед `</body>`, без метки `noindex`; политика и согласие —
`noindex, follow` и без счётчиков, как сейчас на сайте. `send.php` в пакет не входит: на сервере он с настоящим паролем почты.
Если в папке страницы на сервере лежит `index.html`, его нужно убрать, чтобы сервер отдавал `index.php`.

Формы: `send.php` на сервере читает только `name`, `company`, `phone`, `email`, `type` и `msg`. Остальные поля формы
(например, «Вид производства» и «Ближайшая проверка» на странице пищевых производств) и адрес страницы перед отправкой
собираются в текст `msg` — так они попадают в письмо с заявкой.

### Выкладка на Timeweb

Песочница Perplexity к FTP Timeweb не подключается, поэтому `tools/deploy/run_all.sh` запускается в «Терминале» на Mac mini.
Рядом со скриптом — `pkg/` (содержимое `dist/timeweb/`), `MANIFEST.sha256`, `deploy.conf` (пример —
`tools/deploy/deploy-2026-11-06-site06122026v1.conf`) и временный `.netrc` с доступом FTP; без `deploy.conf` скрипт не запускается.

- `deploy` — копия заменяемых файлов и сверка с `EXPECTED_BEFORE` (если на сервере не те файлы — выкладка отменяется, прежняя копия не трогается),
  загрузка новых файлов, затем заменяемых, сверка всех файлов на сервере с пакетом; при ошибке — откат. В конце `.netrc` удаляется.
- `rollback` — вернуть заменённые файлы из `backup/`. `check` — подключение и список файлов.
- Timeweb не принимает частые подключения, поэтому файлы передаются пакетами — одно подключение FTP на этап.
- Копия, журнал, скрипт и `deploy.conf` сохраняются в `~/<NAME>` на Mac.
